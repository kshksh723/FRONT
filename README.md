## 커맨드 라인을 사용하여 Git 변경 사항 커밋하기

**모든 변경 사항 스테이징**:

  
   ```bash
   git add .
   메시지를 포함하여 커밋하기:
   git commit -m "커밋 메시지"
   원격 저장소에 변경 사항 푸시하기:
   git push
   ```
------------------------
   스테이징 : 다음 커밋에 포함될 특정 변경 사항(예: 파일 추가, 수정 또는 삭제)을 준비하는 것, 커밋하려는 변경 사항을 선택하는 커밋 전 단계
