# 📸 기억 조각 (Memory Shards)
추억을 저장하고 공유하는, 당신만의 인스타그램!


# ✨ 프로젝트 소개
'기억 조각'은 사용자들이 소중한 추억들을 사진과 함께 기록하고, 이를 다른 사람들과 공유하며 소통할 수 있도록 만든 추억 기반 소셜 네트워킹 서비스(SNS) 웹사이트입니다. 
마치 개인의 '기억 창고'처럼, 시간의 흐름 속에서 잊힐 수 있는 순간들을 영구적으로 보존하고, 과거를 되돌아보는 즐거움을 제공합니다.


# 주요 기능:

추억 기록: 사진 업로드와 함께 내용, 날짜, 태그 등을 추가하여 추억을 기록합니다.

피드: 친구 및 팔로우하는 사용자의 최신 추억들을 확인합니다.

공유 및 소통: 좋아요, 댓글 기능을 통해 다른 사용자의 추억에 공감하고 소통합니다.

개인 프로필: 자신의 모든 추억 기록을 한눈에 모아보고 관리합니다.

### 💻 기술 스택 (Tech Stack)

이 프로젝트는 **프론트엔드와 백엔드가 분리**된 구조입니다.

#### 📦 프론트엔드 (Frontend - React & Vite)
| 기술 | 설명 |
| :--- | :--- |
| **React** | 사용자 인터페이스 구축을 위한 핵심 라이브러리 (SPA 구현) |
| **Vite** | 초고속 개발 서버 및 빌드 도구. **ESM 기반**으로 빠른 HMR 및 프로덕션 빌드 속도 제공 |
| **TypeScript** | 정적 타입 시스템 도입으로 코드 안정성 및 유지보수성 향상 |
| **Styled-Components** | 컴포넌트 기반 스타일링 (CSS-in-JS) |
| **Recoil / Zustand** | 전역 상태 관리를 위한 라이브러리 |
| **Axios** | Spring Boot API 서버와의 **비동기 통신(REST API 호출)** 처리 |

#### ⚙️ 백엔드 (Backend - Spring Boot)
| 기술 | 설명 |
| :--- | :--- |
| **Spring Boot** | 빠르고 안정적인 **RESTful API 서버** 구축 |
| **Java** | 백엔드 로직의 주요 프로그래밍 언어 |
| **Spring Security & JWT** | 사용자 **인증**, **인가** 및 **토큰 기반(JWT)** 보안 구현 |
| **Spring Data JPA** | 데이터베이스 관리 및 ORM (Object-Relational Mapping) |
| **AWS S3** | 사용자가 업로드하는 **대용량 이미지 파일** 저장 및 관리 |

#### 💾 데이터베이스 및 인프라
| 기술 | 설명 |
| :--- | :--- |
| **MySQL / PostgreSQL** | 안정적인 관계형 데이터베이스(RDBMS) |
| **CORS 설정** | 프론트엔드(React)와 백엔드(Spring Boot) 간의 **도메인 간 통신 허용** |
