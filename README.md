# 📸 기억 조각 (Memory Shards)

추억을 저장하고 공유하는, 당신만의 인스타그램!

데모 링크 : [인스타그램](https://www.instagram.com/)

# ✨ 프로젝트 소개

'기억 조각'은 사용자들이 소중한 추억들을 사진과 함께 기록하고, 이를 다른 사람들과 공유하며 소통할 수 있도록 만든 추억 기반 소셜 네트워킹 서비스(SNS) 웹사이트입니다.
마치 개인의 '기억 창고'처럼, 시간의 흐름 속에서 잊힐 수 있는 순간들을 영구적으로 보존하고, 과거를 되돌아보는 즐거움을 제공합니다.

# 주요 기능:

추억 기록: 사진 업로드와 함께 내용, 날짜, 태그 등을 추가하여 추억을 기록합니다.

피드: 친구 및 팔로우하는 사용자의 최신 추억들을 확인합니다.

공유 및 소통: 좋아요, 댓글 기능을 통해 다른 사용자의 추억에 공감하고 소통합니다.

개인 프로필: 자신의 모든 추억 기록을 한눈에 모아보고 관리합니다.


# ⚙️ 핵심 구현 기능
| 구분 | 상세 기능 |
| :--- | :--- |
| **고성능 피드** | Next.js SSR을 통한 빠른 피드 렌더링 및 무한 스크롤 구현. |
| **인증/인가** | Spring Security와 JWT를 활용한 안전한 사용자 인증 시스템. |
| **파일 관리** | 이미지 업로드 및 AWS S3를 활용한 정적 파일 저장. |


### 💻 기술 스택 (Tech Stack)
| 분야 | 핵심 기술 | 사용 목적 |
| :--- | :--- | :--- |
| **프론트엔드** | **Next.js (TS)** | **SSR/SEO** 최적화, 고성능 UI 구현. |
| **백엔드/API** | **Spring Boot (Java)** | **RESTful API** 서버, JWT 기반 인증/인가 처리. |
| **데이터베이스** | **PostgreSQL** | MariaDB 외 다른 **관계형 DB 경험** 확보. |
| **ORM** | **Spring Data JPA** | 데이터베이스와의 효율적인 상호작용. |
